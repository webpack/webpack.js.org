The `NoEmitOnErrorsPlugin` allows you to avoid emitting assets when there are any errors. It is enabled by default in `production` mode, where [`optimization.emitOnErrors`](/configuration/optimization/#optimizationemitonerrors) defaults to `false`; use that option to enable or disable it.

**webpack.config.js**

```js
export default {
  plugins: [new webpack.NoEmitOnErrorsPlugin()],
};
```
